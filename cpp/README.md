# Original C++ implementation

`Bead12.cpp` is the original coursework source supplied for the Bara Tehni project.

## Platform note

The program includes:

```cpp
#include <windows.h>
```

It uses Windows console APIs for text colors and `Sleep`, so the original source is intended to compile and run on Windows.

## Example compilation

```powershell
g++ .\Bead12.cpp -o .\BaraTehni.exe
.\BaraTehni.exe
```

The original file has been preserved without rewriting it into JavaScript. The website in the repository root is a separate browser recreation.
